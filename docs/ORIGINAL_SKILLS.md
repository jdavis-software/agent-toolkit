# Original skills, personal collection

Jordan's Agent Toolkit Collection is a personal home for useful agent skills, practical workflows, and selected tools. The primary skill catalog contains local implementations, not cards promoting entire external skill libraries.

## Authoring decision

Research the problems worth solving, then write a task contract: activation, inputs, expected artifact, constraints, failure handling, and evaluation cases. Write the instructions and examples for that contract without using another skill's prose or distinctive structure as a rewriting template. Improve the package through actual evaluations, not cosmetic word changes.

This is a requirements-first authoring practice, not a legal clean-room certification or a guarantee of worldwide uniqueness. Public engineering ideas may be shared across implementations. Do not claim that a filename change, synonym substitution, or removal of a source link establishes independent authorship.

New packages should have a practical example and synthetic trigger, boundary, and non-trigger evaluation cases. Those cases are evaluation inputs until a recorded host run exists. Repository and website checks do not establish agent effectiveness.

## What visitors see

The site leads with Jordan's name and the collection's own skills. Each original skill links to its own SKILL.md, not to an upstream skill package. Workflows demonstrate how the skills fit together. Third-party executable tools remain separately identified under Tools; a skill describing a tool does not become an implementation of that tool.

Keep technical source citations where a claim needs evidence. Avoid inventing prior personal usage, performance gains, or cross-host compatibility. AI-assisted authoring is disclosed without presenting the collection as a rebranded upstream project.

## Provenance and retained notices

Actual reused code, text, assets, and dependencies keep the notices required by their terms. Adapted material must remain identified as adapted. Existing historical research references can stay in ATTRIBUTION.md without making every original skill a reference listing.

The U.S. Copyright Office distinguishes ideas and methods from their expression: https://www.copyright.gov/help/faq/faq-protect.html . The MIT text illustrates a notice-retention requirement for copies or substantial portions: https://opensource.org/license/mit . These sources explain why paraphrasing is not a blanket license exemption; this project makes no legal clearance claim.
