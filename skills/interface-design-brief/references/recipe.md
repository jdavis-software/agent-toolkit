# Interface Design Brief — original recipe

## Recipe: a one-page design contract

Document the primary task, three prioritized actions, density target, type hierarchy, semantic colors, selected icon family, component reuse, responsive strategy and required state matrix. Give each design choice a reason tied to the task.

The published frontend guide is an original composition using the toolkit’s existing style. It does not import UI UX Pro Max’s style database or claim that any particular aesthetic improves conversion without measurement.

## Failure fixture

A polished dashboard concept assumes short labels and full permissions; the real screen has long names, no data and a read-only user.

**Expected:** Produce usable empty/read-only/long-content compositions and a clear action hierarchy before declaring the design ready.

This recipe is synthetic. A consuming project must bind real versions, components, tools and authority before applying it.
